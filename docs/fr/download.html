Fermez votre DAW avant d'installer ou de mettre à jour — une DAW ouverte verrouille le fichier du plugin.

Windows. Lancez HOUZY-Setup.exe. Le plugin est installé dans C:\Program Files\Common Files\VST3.

Windows sans l'installateur. Décompressez l'archive VST3 et placez HOUZY.vst3 dans C:\Program Files\Common Files\VST3.

macOS. Double-cliquez sur HOUZY-Installer.pkg et cochez les formats souhaités : AU pour Logic Pro et GarageBand, VST3 pour tout le reste. Les deux sont Universal (Apple Silicon et Intel).

Le paquet n'est pas encore signé avec un certificat Apple, donc macOS le bloque au premier lancement. Clic droit sur le fichier → Ouvrir → de nouveau Ouvrir dans l'avertissement. Ou : Réglages Système → Confidentialité et sécurité → Ouvrir quand même. Rien n'est cassé — macOS traite ainsi tous les installateurs non signés.

Installation manuelle. Placez HOUZY.vst3 dans /Library/Audio/Plug-Ins/VST3/ ou HOUZY.component dans /Library/Audio/Plug-Ins/Components/, puis levez la quarantaine dans le Terminal (uniquement la ligne correspondant à ce que vous avez installé) :

xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/HOUZY.vst3
xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/HOUZY.component

Redémarrez votre DAW et relancez l'analyse des plugins.

Essai et activation

  1. Ouvrez HOUZY. La fenêtre de licence propose un essai gratuit — tout fonctionne pendant sa durée. Le temps restant s'affiche dans la fenêtre et dans la carte ACRONA.
  2. Pour conserver HOUZY, appuyez sur BUY. Le paiement se fait sur Gumroad ; votre clé de licence arrive dans l'e-mail d'achat et se trouve toujours dans votre bibliothèque Gumroad.
  3. Dans HOUZY, appuyez sur ACTIVATE, collez la clé, puis appuyez de nouveau sur ACTIVATE. Une connexion Internet n'est nécessaire qu'une fois ; ensuite HOUZY fonctionne hors ligne.
  4. Une clé fonctionne sur deux ordinateurs. Pour passer à un nouvel ordinateur : ouvrez la fenêtre de licence sur l'ancien et appuyez sur DEACTIVATE.

En cas de problème

  • Pas d'e-mail avec la clé — vérifiez l'adresse utilisée pour la commande, y compris les spams, puis votre bibliothèque Gumroad : la clé s'y trouve toujours. Toujours rien ? Contactez le support Gumroad — il gère les commandes et les clés.
  • « Pas de connexion au serveur de licence » — vérifiez votre connexion Internet et appuyez de nouveau sur ACTIVATE. Un incident du serveur ne retire jamais une licence déjà active.
  • « Déjà active sur le nombre maximal d'ordinateurs » — désactivez-la sur l'un d'eux, ou écrivez-nous.
  • Tout autre problème : le bouton REPORT de la fenêtre de licence copie tout ce dont nous avons besoin — collez-le dans votre e-mail.

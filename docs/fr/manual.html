Comment masteriser de la musique électronique avec HOUZY

Le manuel de HOUZY : par où commencer (AMOUNT à 15–30), ce que fait chaque réglage sur le son, et comment affiner un morceau de musique électronique et de dance.

AMOUNT · INPUT · CYCLES · RELEASE

Deux minutes entre l'ouverture de HOUZY et un morceau dense et homogène. Le même guide est intégré à HOUZY, dans la carte ACRONA.

Mode

Choisissez HOUZY — c'est lui qui donne la meilleure qualité sonore.

1. AMOUNT

Commencez par le bouton AMOUNT. Pour un morceau bien mixé, 15 à 30 donnent généralement une compression douce et modérée. Pour tout le reste, réglez à l'oreille.

2. INPUT

Une fois la compression satisfaisante, montez INPUT en surveillant l'indicateur LUFS. Pour un son doux, −10 à −9 LUFS suffisent.

3. CYCLES

Pour un kick doux, réglez entre 3 et 4.

4. RELEASE

Laissez AUTO activé : le plugin mesure la vitesse à laquelle les sons de votre morceau s'éteignent et règle le release à votre place.

5. BEAT ou SMART

Choisissez à l'oreille.

  • BEAT garde le release exactement comme réglé : un son plus régulier, qui pulse avec le beat.
  • SMART traite le release comme un maximum : un son qui s'éteint plus tôt est relâché plus tôt. Plus aéré et plus naturel.

Réglages fins

  • DASH — si la compression sonne bien mais que le morceau n'est pas encore assez homogène, ajoutez un peu de DASH.
  • UPWARD — remonte les passages faibles : queues de réverbération, air, haut du spectre.
  • CLIP SHAPE — légère saturation sur tout le morceau. Le volume est compensé automatiquement : vous entendez la couleur, pas un gain de niveau.
  • ALL MIX — si le morceau est globalement dense mais que, par exemple, les aigus ou les médiums ressortent, activez ALL MIX et baissez cette bande avec son bouton. Pour voir quelles fréquences couvre une bande, laissez le pointeur sur son bouton quelques secondes — une info-bulle indique la plage.

Clipper : HI-Q ou ACR

Nous recommandons ACR, notre propre clipper. Il déplace la distorsion là où le coup la masque, les attaques restent donc propres. Cela reste une affaire de goût — essayez les deux.

OVERSAMPLE

16x suffit largement pendant le travail ; passez à 32x pour le rendu final.

TRUE PEAK

Le bouton TP se trouve sur le bouton OUTPUT. Activez-le pour un export destiné au streaming : il supprime les crêtes inter-échantillons qui craquent après la conversion en MP3/AAC.

En bref

  1. AMOUNT de 15 à 30, CYCLES de 3 à 4.
  2. Montez INPUT si nécessaire.
  3. Un peu de DASH et d'UPWARD selon votre goût.
  4. Dans ALL MIX, baissez ce qui ressort.
  5. C'est tout.

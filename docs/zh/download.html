安装或更新前请关闭 DAW——运行中的 DAW 会锁定插件文件。

Windows。运行 HOUZY-Setup.exe。插件会安装到 C:\Program Files\Common Files\VST3。

Windows 不用安装程序。解压 VST3 压缩包，把 HOUZY.vst3 放进 C:\Program Files\Common Files\VST3。

macOS。双击 HOUZY-Installer.pkg，勾选需要的格式：AU 用于 Logic Pro 和 GarageBand，VST3 用于其他所有宿主。两者都是 Universal（Apple Silicon 和 Intel）。

安装包还没有 Apple 证书签名，所以 macOS 首次打开时会阻止它。右键点击文件 → 打开 → 在警告中再点一次 打开。或者：系统设置 → 隐私与安全性 → 仍要打开。这不是故障——macOS 对所有未签名的安装程序都是这样。

手动安装。把 HOUZY.vst3 放进 /Library/Audio/Plug-Ins/VST3/，或把 HOUZY.component 放进 /Library/Audio/Plug-Ins/Components/，然后在终端中解除隔离（只运行你所安装内容对应的那一行）：

xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/HOUZY.vst3
xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/HOUZY.component

重启 DAW 并重新扫描插件。

试用与激活

  1. 打开 HOUZY。许可证窗口会提供免费试用——试用期内一切功能可用。剩余时间显示在窗口和 ACRONA 卡片中。
  2. 要保留 HOUZY，请点 BUY。付款在 Gumroad 进行；你的许可证密钥会随购买邮件发送，并且始终保存在你的 Gumroad 资料库中。
  3. 在 HOUZY 中点 ACTIVATE，粘贴密钥，再点一次 ACTIVATE。只需联网一次，之后 HOUZY 可离线使用。
  4. 一个密钥可用于两台电脑。换新电脑时：在旧电脑上打开许可证窗口并点 DEACTIVATE。

如果出了问题

  • 没收到带密钥的邮件——检查下单时填写的邮箱（包括垃圾邮件），然后查看你的 Gumroad 资料库：密钥一直在那里。还是没有？联系 Gumroad 客服——订单和密钥由他们负责。
  • “无法连接许可证服务器”——检查网络后再点一次 ACTIVATE。服务器故障绝不会收回已激活的许可证。
  • “已在最大数量的电脑上激活”——在其中一台上解除激活，或者写信给我们。
  • 其他任何问题：许可证窗口中的 REPORT 按钮会复制我们需要的一切——粘贴到邮件里即可。

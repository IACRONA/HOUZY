如何用 HOUZY 为电子音乐做母带

HOUZY 使用手册：从哪里开始（AMOUNT 设在 15–30），每个控件对声音有什么作用，以及如何精调一条电子或舞曲曲目。

AMOUNT · INPUT · CYCLES · RELEASE

从打开 HOUZY 到得到一条紧实、均匀的曲目，只需两分钟。同样的指南也内置在 HOUZY 的 ACRONA 卡片中。

模式

选择 HOUZY——它的音质最好。

1. AMOUNT

先从 AMOUNT 旋钮开始。对于混音良好的曲目，15 到 30 通常能带来柔和、适度的压缩。其他情况请用耳朵来调。

2. INPUT

压缩感觉合适后，一边看 LUFS 表一边提高 INPUT。想要柔和的声音，−10 到 −9 LUFS 就够了。

3. CYCLES

想要柔和的底鼓，把它设在 3 到 4 之间。

4. RELEASE

保持 AUTO 开启：插件会测量曲目中声音衰减的快慢，并为你设定释放。

5. BEAT 还是 SMART

用耳朵来选。

  • BEAT 严格按设定保持释放：声音更稳定，随节拍律动。
  • SMART 把释放当作上限：先衰减的声音会被更早放开。更通透、更自然。

精调

  • DASH——如果压缩听起来不错，但曲目还不够均匀，就加一点 DASH。
  • UPWARD——提升安静部分：混响尾音、空气感、高频。
  • CLIP SHAPE——对整条曲目做轻度饱和。响度会自动匹配，所以你听到的是音色，而不是音量变大。
  • ALL MIX——如果曲目整体听起来很紧实，但比如高频或中频突出，就打开 ALL MIX，用该频段的旋钮把它压下来。想知道某个频段覆盖哪些频率，把鼠标在它的旋钮上停几秒——提示会显示范围。

削波器：HI-Q 还是 ACR

我们推荐自研削波器 ACR。它把失真移到被敲击声掩盖的位置，所以起音保持干净。不过这仍是口味问题——两种都试试。

OVERSAMPLE

工作时 16x 已足够；最终导出时用 32x。

TRUE PEAK

TP 按钮在 OUTPUT 旋钮上。导出用于流媒体时打开它：它会去除转换成 MP3/AAC 后会爆音的样本间峰值。

简而言之

  1. AMOUNT 15 到 30，CYCLES 3 到 4。
  2. 需要时提高 INPUT。
  3. 按喜好加一点 DASH 和 UPWARD。
  4. 在 ALL MIX 中把突出的部分压下来。
  5. 完成。

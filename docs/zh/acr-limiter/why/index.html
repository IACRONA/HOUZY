ACR LIMITER

一个增益、削波器，还是每一个半波

ACR LIMITER 与普通限制器、削波器和多频段限制器有什么不同。

更新于 2026 年 11 月 19 日

ACR LIMITER 是什么？

ACR LIMITER 是 HOUZY 原班人马打造的母带限制器插件（VST3）。一个 AMOUNT 旋钮推高电平，四级处理依次捕捉峰值，每一级只处理自己最擅长的部分：ACR 削波器处理 ~4 kHz 以上的短峰值，T8 / T9 限制器稳住低频、底鼓本体和中频，六个线性相位频段防止低频峰值压低高频，TRUE PEAK 守住采样点之间的上限。

整个峰值只用一个增益。

普通限制器就是 output = gain × signal，只要有任何峰值过大，增益就被拉下去。所有经典的抱怨都由此而来：

  • 底鼓压低高频 — 低频峰值会把踩镲、人声和混响尾音一起拉下去。这是发生在链路最末端的抽吸。
  • 每一下都带毛刺 — 增益在低频波形的中间移动，把波形弄弯；在 50 Hz 左右的底鼓上，你会听到脏而发糙的低频。
  • 高频发闷 — 生硬的削波器切掉波形；它的误差是宽频的，落在踩镲和空气感上。
  • 采样点间过载 — 导出文件显示 −0.1 dBFS，但经过 MP3 或流媒体编码后削波。

常见的做法是把削波器和限制器叠在一起，指望它们别打架。ACR LIMITER 把两者做成一条链路，每一级只取自己的那部分：削波器从不接触低频，低频限制器从不在波形中间移动，各频段防止一个峰值把整个混音拉下去。

削波器或多频段限制器有帮助，但只解决一半

削波器能保住冲击力并提高响度，但它的切削是宽频的：推得狠，低频就会发糙，高频就会发闷。多频段限制器能阻止底鼓压低踩镲，但在每个频段内部，仍有一个增益在波形中间移动。ACR LIMITER 把削波器从低频上移开，并且只在波形过零处移动低频增益。

更响，却不脏。

ACR 减去恰好落在峰值上的一个短脉冲，而不是把峰值切掉。它的频谱把失真放在高频，那里的踩镲和起音会将其掩蔽；深度随 AMOUNT 从 0.5 dB 增加到 2 dB。

T8 只在波形过零处改变增益：底鼓和低音的每个半波被整体压低，所以形状与原来完全一样。T9 跟随低频的包络，平滑地放开长音 sub，不会抖动。一个开关，10 ms 交叉淡化，默认 T9。

其余由 CEILING、CHARACTER（限制器之前的轻度饱和）和 OUTPUT 设定。BYPASS 与延迟对齐，所以你对比的是同一时刻。

什么时候别的限制器更合适

录音和现场演奏，每一毫秒的延迟都很重要。ACR LIMITER 向前看 0.1 s，专为总线和最终响度而设计。

常见问题

ACR LIMITER 会抽吸吗？

比单增益限制器少得多：各频段逐个限制，所以低频峰值不会把高频拉下去，低频增益只在过零处移动。

T8 还是 T9？

两者都稳住低频。T8 保持每个半波完整；T9 跟随包络，对长音 sub 更平滑。播放时切换，用耳朵选择。

可以和 HOUZY 一起用吗？

可以：先用 HOUZY 做均匀压缩，最后用 ACR LIMITER 决定响度和上限。两个插件，两份许可证。

支持哪些格式和 DAW？

Windows 10/11 64 位上的 VST3：Ableton Live、FL Studio、Cubase、Reaper、Bitwig 以及其他 VST3 宿主。

四级处理，各司其职。

AMOUNT 推高电平，然后整条链路依次捕捉峰值：ACR 处理 ~4 kHz 以上的短峰值，T8 / T9 稳住低频、底鼓本体和中频，TRUE PEAK 守住采样点之间的上限。

削波器永远排在限制器之前。低频从不进入削波器，所以不会发糙；高频从不进入慢速限制器，所以不会抽吸。

其余由 CEILING、CHARACTER 和 OUTPUT 设定。BYPASS 与延迟对齐，所以你对比的是同一时刻。

整个峰值只用一个增益。

普通限制器只要有任何峰值过大，就会把整首曲子压下去：

  • 底鼓压低高频 — 低频峰值会把踩镲和人声一起拉下去。
  • 每一下都带毛刺 — 增益在低频波形的中间移动，把波形弄弯。
  • 高频发闷 — 生硬的削波器切掉波形，它的误差散布在整个频谱上。
  • 采样点间过载 — 导出文件在 MP3 或流媒体编码后削波。

ACR——不再砍伤高频的削波器。

切削很突兀，它的误差是宽频的：底鼓的每一下，都会把这份误差从踩镲、人声和尾音中扣掉。

ACR 减去恰好落在峰值上的一个短脉冲。它的频谱把失真放在高频，那里的踩镲和起音会将其掩蔽。深度随 AMOUNT 增加：起始 0.5 dB，满载时最高 2 dB。

T8——半波限制器。

T8 只在波形过零的地方改变增益。底鼓和贝斯的每个半波都被整体降低，所以形状完全保持原样，只有高度改变。

六个线性相位频段：低频峰值不会压低高频，每个频段各自限制。

T9 — 面向低频的包络限制器。

T9 读取低频的包络，而不是单个波形：增益托住音符的整个顶部并平滑地放开，长音 sub 也不会抖动。

T8 | T9 是同一个开关，切换时以 10 ms 交叉淡化，没有空档。默认是 T9。

母带限制器需要的一切。

  • TRUE PEAK — 默认开启，适用于流媒体和 MP3 导出。
  • CEILING — −12…0 dB。
  • CHARACTER — 限制器之前的轻度饱和。
  • OUTPUT — 限制器之后的电平。
  • LINEAR | NATURAL | CLEAN L — 各频段的相位。
  • OVERSAMPLE — 4x 到 64x，默认 8x。
  • MIX & MASTER — 插件内置的混音与母带工程师目录。

为什么选 ACR LIMITER

它解决的问题。

干净的低频

低音和底鼓以整个半波为单位被压低，所以波形保持原样：没有毛刺，没有爆裂。

明亮的高频

ACR 把削波误差移到踩镲能够掩蔽的地方：即使推得很狠，高频依然通透。

没有抽吸

每个频段各自限制：底鼓的峰值绝不会把人声和高频拉下去。

适合流媒体

TRUE PEAK 默认开启：经过 MP3、AAC 或流媒体编码后，没有采样点间过载。

大家常问的问题。

T8 和 T9 有什么区别？

两者都稳住低频和底鼓本体。T8 只在波形过零处改变增益，所以每个半波都保持原有形状。T9 跟随低频的包络，平滑地放开长音 sub。默认是 T9；切换后用耳朵选择。

可以和 HOUZY 一起用吗？

可以。在总线上把 ACR LIMITER 放在 HOUZY 之后：HOUZY 把压缩做均匀，ACR LIMITER 决定最终响度和上限。它们是两个独立的插件，各有各的许可证。

我的音频会离开电脑吗？

绝不会。所有处理都在你的电脑上完成。插件只在检查更新和激活许可证时联网。详情见隐私政策（英文）。

支持哪些系统和 DAW？

Windows 10/11 64 位上的 VST3：Ableton Live、FL Studio、Cubase、Reaper、Bitwig 以及其他 VST3 宿主。macOS 10.15+（Apple Silicon 和 Intel）：VST3 和 AU，包括 Logic Pro。

会增加多少延迟？

约 0.1 s（限制器和线性相位频段的前瞻）。插件会把延迟报告给 DAW，由 DAW 补偿，所以各轨道保持同步。

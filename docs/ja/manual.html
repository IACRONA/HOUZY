HOUZYで電子音楽をマスタリングする方法

HOUZYマニュアル：どこから始めるか（AMOUNTは15〜30）、各コントロールが音に何をするか、電子音楽・ダンスミュージックのトラックを仕上げる方法。

AMOUNT · INPUT · CYCLES · RELEASE

HOUZYを開いてから、密度があって均一なトラックになるまで2分。同じガイドはHOUZYのACRONAカードにも内蔵されています。

モード

HOUZYを選びます — いちばん音質が良くなります。

1. AMOUNT

まずAMOUNTノブから。しっかりミックスされたトラックなら、15〜30でたいてい自然で穏やかな圧縮になります。それ以外は耳で決めてください。

2. INPUT

圧縮の感じが決まったら、LUFSメーターを見ながらINPUTを上げます。やわらかい音なら−10〜−9 LUFSで十分です。

3. CYCLES

やわらかいキックには、3〜4に設定します。

4. RELEASE

AUTOはオンのままに：プラグインがトラック内の音の減衰の速さを測り、リリースを設定します。

5. BEATかSMARTか

耳で選んでください。

  • BEATはリリースを設定どおりに保ちます：より安定して、ビートに合わせて脈打つ音。
  • SMARTはリリースを最大値として扱います：早く消える音は早く離されます。より空気感があり、自然です。

仕上げの調整

  • DASH — 圧縮の音はいいのにトラックがまだ均一でないときは、DASHを少し加えます。
  • UPWARD — 小さな部分を持ち上げます：リバーブの余韻、空気感、高域。
  • CLIP SHAPE — トラック全体にかかる軽いサチュレーション。音量は自動で補正されるので、聴こえるのは音量アップではなく色合いです。
  • ALL MIX — 全体は密度があるのに、たとえば高域や中域だけが突き出ているときは、ALL MIXをオンにして、その帯域のノブで下げます。そのバンドがどの周波数をカバーしているかは、ノブにポインターを数秒置くとヒントで範囲が表示されます。

クリッパー：HI-QかACRか

自社開発のACRをおすすめします。歪みを打撃音が隠してくれる位置へ移すので、アタックがクリーンなままです。とはいえ好みの問題 — 両方試してみてください。

OVERSAMPLE

作業中は16倍で十分です。最終レンダリングでは32倍を使います。

TRUE PEAK

TPボタンはOUTPUTノブの上にあります。ストリーミング用に書き出すときはオンにしてください：MP3/AAC変換後にパチパチ鳴る、サンプル間ピークを取り除きます。

要点

  1. AMOUNTは15〜30、CYCLESは3〜4。
  2. 必要ならINPUTを上げます。
  3. DASHとUPWARDは好みで少しだけ。
  4. ALL MIXで、突き出ている部分を下げます。
  5. 以上です。

これがすべてHOUZYでできます

インストールやアップデートの前にDAWを閉じてください — DAWが起動中だと、プラグインのファイルがロックされます。

Windows。ACR-LIMITER-Setup.exeを実行してください。プラグインはC:\Program Files\Common Files\VST3にインストールされます。

インストーラーを使わないWindows。VST3のアーカイブを解凍し、ACR LIMITER.vst3をC:\Program Files\Common Files\VST3に置きます。

DAWを再起動し、プラグインを再スキャンしてください。

お試しと認証

  1. ACR LIMITERを開きます。ライセンス画面に無料お試しが表示され、期間中はすべて動作します。残り時間はこの画面とACRONAカードに表示されます。
  2. ACR LIMITERを継続して使うには、BUYを押します。お支払いはGumroadで、ライセンスキーは購入メールに届き、Gumroadライブラリにも常に保管されます。
  3. ACR LIMITERでACTIVATEを押し、キーを貼り付けて、もう一度ACTIVATEを押します。インターネット接続が必要なのは最初の1回だけで、その後はオフラインで動作します。
  4. 1つのキーで2台のコンピューターで使えます。新しいコンピューターに移るときは、古い方でライセンス画面を開き、DEACTIVATEを押してください。

うまくいかないときは

  • キーのメールが届かない — 注文に使ったメールアドレスを、迷惑メールも含めて確認し、次にGumroadライブラリを見てください。キーは必ずそこにあります。それでも見つからなければ、Gumroadサポートへ — 注文とキーを扱っています。
  • 「ライセンスサーバーに接続できません」 — インターネット接続を確認して、もう一度ACTIVATEを押してください。サーバーの一時的な不調で、すでに有効なライセンスが失われることはありません。
  • 「すでに最大台数のコンピューターで有効です」 — そのうち1台で認証を解除するか、私たちにご連絡ください。

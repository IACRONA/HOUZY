ACR LIMITER

ゲイン1つか、クリッパーか、半波ごとか

ACR LIMITERが通常のリミッター、クリッパー、マルチバンドリミッターとどう違うのか。

2026年11月19日更新

ACR LIMITERとは？

ACR LIMITERは、HOUZYの開発元によるマスタリング用リミッタープラグイン（VST3）です。つまみはAMOUNT1つでレベルを上げ、4つのステージが順番にピークを捉えて、それぞれ最も得意な部分だけを受け持ちます。ACRクリッパーは約4 kHz以上の短いピーク、T8 / T9リミッターは低域・キックの胴・中域、6つのリニアフェーズバンドは低域のピークが高域を押し下げるのを防ぎ、TRUE PEAKはサンプル間の上限を守ります。

ピーク全体にゲイン1つ。

通常のリミッターはoutput = gain × signalで、どれかのピークが大きすぎるたびにゲインが引き下げられます。定番の不満はすべてここから生まれます。

  • キックが高域を押し下げる — 低域のピークがハイハット、ボーカル、リバーブの余韻まで一緒に引き下げます。チェーンの最後で起きるポンピングです。
  • ヒットごとのザラつき — 低域の波の途中でゲインが動き、波形を歪めます。50 Hzのキックのまわりでは、濁ってざらついた低域として聞こえます。
  • こもった高域 — 硬いクリッパーは波形を削ります。その誤差は広帯域で、ハイハットや空気感にかかります。
  • サンプル間オーバー — 書き出しでは−0.1 dBFSなのに、MP3やストリーミングのエンコード後にクリップします。

よくある答えは、クリッパーとリミッターを重ねて、ぶつからないよう祈ることです。ACR LIMITERは、この2つをひとつのチェーンに組み込みました。各ステージは自分の担当だけを受け持ちます。クリッパーは低域を見ず、低域リミッターは波の途中で動かず、バンドが1つのピークでミックスの残りが引き下げられるのを防ぎます。

クリッパーやマルチバンドリミッターは助けになりますが、半分だけです

クリッパーはパンチを保って音量を上げますが、削り取りは広帯域です。押し込むと低域が割れ、高域がこもります。マルチバンドリミッターはキックがハイハットを押し下げるのを防ぎますが、各バンドの中では、波の途中で1つのゲインが動いてしまいます。ACR LIMITERは低域からクリッパーを外し、低域のゲインを波がゼロを横切る位置でだけ動かします。

汚さずに、もっと大きく。

ACRはピークを削る代わりに、ピークのちょうど真上に置いた短いパルスを差し引きます。そのスペクトルは歪みを高域側に置くので、ハイハットやアタックがそれをマスクします。深さはAMOUNTとともに0.5 dBから2 dBまで増えます。

T8は波がゼロを横切る位置でだけゲインを変えます。キックとベースの各半波がひと塊として下がるので、形は元のままです。T9は低域のエンベロープに追従し、長いサブノートをばたつきなく滑らかに放します。スイッチは1つ、クロスフェードは10 ms、デフォルトはT9です。

残りはCEILING、CHARACTER（リミッター前段の軽いサチュレーション）、OUTPUTで設定します。BYPASSはレイテンシーに合わせてあるので、同じ瞬間どうしで比較できます。

別のリミッターのほうが向いているとき

レコーディングやライブ演奏のように、1ミリ秒のレイテンシーも重要な場面です。ACR LIMITERは0.1秒先を見るので、マスターバスと最終的な音量のために作られています。

よくある質問

ACR LIMITERはポンピングしますか？

ゲイン1つのリミッターよりはるかに少なくなります。バンドは1つずつリミットされるので、低域のピークが高域を引き下げることはなく、低域のゲインはゼロクロスでしか動きません。

T8かT9か？

どちらも低域を押さえます。T8はすべての半波を丸ごと保ち、T9はエンベロープに追従して、長いサブノートでより滑らかです。再生中に切り替えて、耳で選んでください。

HOUZYと一緒に使えますか？

はい。均一な圧縮のためにHOUZYを先に、音量と上限のためにACR LIMITERを最後に。2つのプラグイン、2つのライセンスです。

対応フォーマットとDAWは？

Windows 10/11（64ビット）のVST3：Ableton Live、FL Studio、Cubase、Reaper、BitwigなどのVST3ホスト。

ACR LIMITER · ACRONA AUDIO音色を保ったまま、音量を上げる。

ACR LIMITERは、HOUZYの開発元によるWindows・macOS対応のリミッタープラグイン（VST3、AU）です。つまみはAMOUNT1つで、レベルを上げます。その後の各ステージは、それぞれが最も得意とするピークの部分だけを受け持ちます。低域のザラつきも、高域のこもりもありません。

3HOUZYの3つの技術をひとつのリミッターにまとめました。ピークを削らずに打ち消すACRクリッパー、低域の波形の形を保つT8 / T9リミッター、そして書き出し後の上限を守るTRUE PEAKです。

4つのステージが、それぞれの持ち場で。

AMOUNTがレベルを上げ、続いてチェーンが順番にピークを捉えます。ACRは約4 kHz以上の短いピーク、T8 / T9は低域・キックの胴・中域、TRUE PEAKはサンプル間の上限を受け持ちます。

クリッパーは常にリミッターの前にあります。低域はクリッパーに入らないので割れず、高域は遅いリミッターに入らないのでポンピングしません。

残りはCEILING、CHARACTER、OUTPUTで設定します。BYPASSはレイテンシーに合わせてあるので、同じ瞬間どうしで比較できます。

ピーク全体にゲイン1つ。

通常のリミッターは、どこかのピークが大きすぎるたびにトラック全体を下げます。

  • キックが高域を押し下げる — 低域のピークがハイハットやボーカルまで一緒に引き下げます。
  • ヒットごとのザラつき — 低域の波の途中でゲインが動き、波形を歪めます。
  • こもった高域 — 硬いクリッパーは波形を削り、その誤差がスペクトル全体に広がります。
  • サンプル間オーバー — MP3やストリーミング用にエンコードすると、書き出した音がクリップします。

ACR — 高域を削らないクリッパー。

削り取りは急激で、その誤差は広帯域です。キックが鳴るたびに、その誤差がハイハットやボーカル、余韻から差し引かれます。

ACRは、ピークのちょうど真上に置いた短いパルスを差し引きます。そのスペクトルは歪みを高域側に置くので、ハイハットやアタックがそれをマスクします。深さはAMOUNTとともに増え、最初は0.5 dB、フルドライブで最大2 dBです。

T8 — 半波リミッター。

T8は、波がゼロを横切る場所でだけゲインを変えます。キックとベースの半波ひとつひとつがまるごと下げられるので、形はそのまま、高さだけが変わります。

リニアフェーズの6バンド。低域のピークが高域を押し下げることはなく、各バンドは個別にリミットされます。

T9 — 低域のためのエンベロープリミッター。

T9は個々の波ではなく低域のエンベロープを読み取ります。ゲインはノートの頂点全体を保持して滑らかに放し、長いサブノートでもばたつきません。

T8 | T9は1つのスイッチです。切り替えは10 msのクロスフェードで、途切れません。デフォルトはT9です。

マスタリング用リミッターに必要なものがすべて。

  • TRUE PEAK — デフォルトでオン。ストリーミングやMP3の書き出し向けです。
  • CEILING — −12…0 dB。
  • CHARACTER — リミッターの前段で軽くサチュレーションをかけます。
  • OUTPUT — リミッター後のレベルです。
  • LINEAR | NATURAL | CLEAN L — バンドの位相です。
  • OVERSAMPLE — 4xから64x、デフォルトは8xです。
  • MIX & MASTER — ミキシング／マスタリングエンジニアのカタログを、プラグイン内で見られます。

なぜACR LIMITER

解決する問題。

クリーンな低域

ベースとキックは半波ごとにまとめて下げるので、波形の形が保たれます。ザラつきも、割れもありません。

輝く高域

ACRはクリッピングの誤差をハイハットがマスクする場所へ移します。音量を上げても、高域は開いたままです。

ポンピングなし

各バンドは個別にリミットされます。キックのピークがボーカルや高域を引き下げることはありません。

ストリーミングも安心

TRUE PEAKはデフォルトでオンです。MP3、AAC、ストリーミングのエンコード後にサンプル間オーバーは出ません。

FAQ

よくあるご質問。

購入前に試せますか？

はい。無料トライアルは14日間、すべての機能が使えます。使い続けるには、Gumroadでライセンスを購入してください。支払いは1回、2台のコンピューターで使える永久ライセンスです。

T8とT9はどう違いますか？

どちらも低域とキックの胴を押さえます。T8は波がゼロを横切る位置でだけゲインを変えるので、すべての半波が形を保ちます。T9は低域のエンベロープに追従し、長いサブノートを滑らかに放します。デフォルトはT9です。切り替えて、耳で選んでください。

HOUZYと一緒に使えますか？

はい。マスターではHOUZYの後にACR LIMITERを置いてください。HOUZYが圧縮を均し、ACR LIMITERが最終的な音量と上限を決めます。別々のプラグインで、ライセンスも別です。

音声データはコンピューターの外に出ますか？

ありません。処理はすべてお使いのコンピューター上で行われます。プラグインがオンラインになるのは、アップデートの確認とライセンスの認証のときだけです。詳しくはプライバシーポリシーをご覧ください。

対応しているシステムとDAWは？

Windows 10/11（64ビット）のVST3：Ableton Live、FL Studio、Cubase、Reaper、BitwigなどのVST3ホスト。macOS 10.15以降（Apple SiliconとIntel）：VST3とAU、Logic Proにも対応します。

レイテンシーはどれくらい増えますか？

約0.1秒です（リミッターとリニアフェーズバンドのルックアヘッド）。プラグインがDAWに通知し、DAWが補正するので、トラックはタイミングを保ちます。

オンラインデモはどういう仕組みですか？

ブラウザー上で、本物のACR LIMITERエンジンが動きます。MP3かWAVを読み込むと、最初の75秒がループ再生されます。トラックがコンピューターの外に出ることはありません。

インストールやアップデートの前にDAWを閉じてください — DAWが起動中だと、プラグインのファイルがロックされます。

Windows。HOUZY-Setup.exeを実行します。プラグインはC:\Program Files\Common Files\VST3にインストールされます。

インストーラーを使わないWindows。VST3のアーカイブを解凍し、HOUZY.vst3をC:\Program Files\Common Files\VST3に置きます。

macOS。HOUZY-Installer.pkgをダブルクリックし、必要な形式にチェックを入れます：Logic ProとGarageBand向けはAU、それ以外はVST3。どちらもUniversal（Apple SiliconとIntel）です。

このパッケージはまだAppleの証明書で署名されていないため、初回起動時にmacOSがブロックします。ファイルを右クリック → 開く → 警告で再度開く。または：システム設定 → プライバシーとセキュリティ → このまま開く。故障ではありません — macOSは署名のないインストーラーをすべてこのように扱います。

手動でインストールする場合。HOUZY.vst3を/Library/Audio/Plug-Ins/VST3/に、またはHOUZY.componentを/Library/Audio/Plug-Ins/Components/に置き、ターミナルで隔離属性を解除します（インストールしたものの行だけ）：

xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/HOUZY.vst3
xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/HOUZY.component

DAWを再起動し、プラグインを再スキャンしてください。

お試しと認証

  1. HOUZYを開きます。ライセンス画面に無料お試しが表示され、期間中はすべて動作します。残り時間はこの画面とACRONAカードに表示されます。
  2. HOUZYを継続して使うには、BUYを押します。お支払いはGumroadで、ライセンスキーは購入メールに届き、Gumroadライブラリにも常に保管されます。
  3. HOUZYでACTIVATEを押し、キーを貼り付けて、もう一度ACTIVATEを押します。インターネット接続が必要なのは最初の1回だけで、その後はオフラインで動作します。
  4. 1つのキーで2台のコンピューターで使えます。新しいコンピューターに移るときは、古い方でライセンス画面を開き、DEACTIVATEを押してください。

うまくいかないときは

  • キーのメールが届かない — 注文に使ったメールアドレスを、迷惑メールも含めて確認し、次にGumroadライブラリを見てください。キーは必ずそこにあります。それでも見つからなければ、Gumroadサポートへ — 注文とキーを扱っています。
  • 「ライセンスサーバーに接続できません」 — インターネット接続を確認して、もう一度ACTIVATEを押してください。サーバーの一時的な不調で、すでに有効なライセンスが失われることはありません。
  • 「すでに最大台数のコンピューターで有効です」 — そのうち1台で認証を解除するか、私たちにご連絡ください。
  • そのほかの問題：ライセンス画面のREPORTボタンが、必要な情報をすべてコピーします — メールに貼り付けてください。

ปิด DAW ก่อนติดตั้งหรืออัปเดต — DAW ที่เปิดอยู่จะล็อกไฟล์ปลั๊กอินไว้

Windows เรียกใช้ HOUZY-Setup.exe ปลั๊กอินจะถูกติดตั้งไว้ที่ C:\Program Files\Common Files\VST3

Windows แบบไม่ใช้ตัวติดตั้ง แตกไฟล์ VST3 แล้ววาง HOUZY.vst3 ไว้ใน C:\Program Files\Common Files\VST3

macOS ดับเบิลคลิก HOUZY-Installer.pkg แล้วเลือกฟอร์แมตที่ต้องการ: AU สำหรับ Logic Pro และ GarageBand, VST3 สำหรับโฮสต์อื่นทั้งหมด ทั้งสองเป็น Universal (Apple Silicon และ Intel)

แพ็กเกจยังไม่ได้เซ็นด้วยใบรับรองของ Apple ดังนั้น macOS จะบล็อกตอนเปิดครั้งแรก คลิกขวาที่ไฟล์ → เปิด → กด เปิด อีกครั้งในคำเตือน หรือ: การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → เปิดต่อไป ไม่มีอะไรเสีย — macOS ทำแบบนี้กับตัวติดตั้งที่ไม่ได้เซ็นทุกตัว

ติดตั้งเอง วาง HOUZY.vst3 ไว้ใน /Library/Audio/Plug-Ins/VST3/ หรือวาง HOUZY.component ไว้ใน /Library/Audio/Plug-Ins/Components/ จากนั้นปลดการกักกันใน Terminal (เฉพาะบรรทัดของสิ่งที่คุณติดตั้ง):

xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/HOUZY.vst3
xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/HOUZY.component

รีสตาร์ต DAW แล้วสแกนปลั๊กอินใหม่

ทดลองใช้และเปิดใช้งาน

  1. เปิด HOUZY หน้าต่างใบอนุญาตจะเสนอการทดลองใช้ฟรี — ระหว่างนั้นทุกอย่างใช้งานได้ เวลาที่เหลือแสดงในหน้าต่างและในการ์ด ACRONA
  2. หากต้องการใช้ HOUZY ต่อ กด BUY ชำระเงินผ่าน Gumroad คีย์ใบอนุญาตของคุณจะมาพร้อมอีเมลยืนยันการซื้อ และอยู่ในคลัง Gumroadของคุณเสมอ
  3. ใน HOUZY กด ACTIVATE วางคีย์ แล้วกด ACTIVATE อีกครั้ง ต้องใช้อินเทอร์เน็ตแค่ครั้งเดียว หลังจากนั้น HOUZY ใช้งานออฟไลน์ได้
  4. คีย์หนึ่งใช้ได้กับคอมพิวเตอร์สองเครื่อง ย้ายไปเครื่องใหม่: เปิดหน้าต่างใบอนุญาตบนเครื่องเก่าแล้วกด DEACTIVATE

หากมีปัญหา

  • ไม่ได้รับอีเมลที่มีคีย์ — ตรวจอีเมลที่ใช้สั่งซื้อ รวมถึงโฟลเดอร์สแปม จากนั้นดูในคลัง Gumroadของคุณ: คีย์อยู่ที่นั่นเสมอ ยังไม่พบ? ติดต่อฝ่ายช่วยเหลือของ Gumroad — พวกเขาดูแลคำสั่งซื้อและคีย์
  • "ไม่สามารถเชื่อมต่อเซิร์ฟเวอร์ใบอนุญาต" — ตรวจอินเทอร์เน็ตแล้วกด ACTIVATE อีกครั้ง เซิร์ฟเวอร์ขัดข้องจะไม่ทำให้ใบอนุญาตที่เปิดใช้งานแล้วหายไป
  • "เปิดใช้งานบนคอมพิวเตอร์ครบจำนวนสูงสุดแล้ว" — ยกเลิกการเปิดใช้งานบนเครื่องใดเครื่องหนึ่ง หรือเขียนถึงเรา
  • ปัญหาอื่น ๆ: ปุ่ม REPORT ในหน้าต่างใบอนุญาตจะคัดลอกทุกอย่างที่เราต้องการ — วางลงในอีเมลของคุณ

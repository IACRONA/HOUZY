ACR LIMITER · ACRONA AUDIOความดังที่ยังคงโทนเสียงเดิม

ACR LIMITER คือปลั๊กอินลิมิตเตอร์ (VST3, AU) สำหรับ Windows และ macOS จากผู้สร้าง HOUZY ปุ่ม AMOUNT ปุ่มเดียวดันระดับขึ้น แล้วแต่ละขั้นที่ตามมาจะรับเฉพาะส่วนของพีคที่จัดการได้ดีที่สุด ไม่มีความหยาบในย่านเบส ไม่มีย่านสูงที่อับทึบ

3สามเทคโนโลยีจาก HOUZY รวมเป็นลิมิตเตอร์เดียว: คลิปเปอร์ ACR ที่หักล้างพีคแทนการตัดทิ้ง, ลิมิตเตอร์ T8 / T9 ที่รักษารูปร่างของทุกคลื่นเบส และ TRUE PEAK ที่เฝ้าเพดานหลังการส่งออก

สี่ขั้น แต่ละขั้นอยู่ในที่ของตัวเอง

AMOUNT ดันระดับขึ้น จากนั้นสายประมวลผลจะจับพีคตามลำดับ: ACR รับพีคสั้น ๆ เหนือ ~4 kHz, T8 / T9 คุมเบส ตัวคิก และย่านกลาง, TRUE PEAK เฝ้าเพดานระหว่างแซมเปิล

คลิปเปอร์อยู่หน้าลิมิตเตอร์เสมอ เบสไม่เคยเข้าคลิปเปอร์ จึงไม่แตกพร่า ย่านสูงไม่เคยเข้าลิมิตเตอร์ที่ช้า จึงไม่ปั๊ม

CEILING, CHARACTER และ OUTPUT ตั้งค่าที่เหลือ BYPASS ถูกจัดให้ตรงกับเลเทนซี คุณจึงเปรียบเทียบช่วงเวลาเดียวกันพอดี

เกนเดียวสำหรับทั้งพีค

ลิมิตเตอร์ทั่วไปจะลดทั้งแทร็กลงทุกครั้งที่มีพีคใดดังเกินไป:

  • คิกกดย่านสูง — พีคเบสดึงไฮแฮตและเสียงร้องลงไปด้วย
  • ความหยาบในทุกจังหวะ — เกนขยับกลางคลื่นเบสแล้วทำให้คลื่นงอ
  • ย่านสูงอับทึบ — คลิปเปอร์แบบแข็งตัดรูปคลื่น และความคลาดเคลื่อนของมันกระจายไปทั่วสเปกตรัม
  • โอเวอร์ระหว่างแซมเปิล — ไฟล์ที่ส่งออกคลิปหลังเข้ารหัส MP3 หรือสตรีมมิง

ACR — คลิปเปอร์ที่ไม่สับย่านสูง

การตัดนั้นกระชาก และความคลาดเคลื่อนของมันเป็นแบบบรอดแบนด์: ทุกจังหวะคิกหักความคลาดเคลื่อนนั้นออกจากไฮแฮต เสียงร้อง และหางเสียง

ACR หักพัลส์สั้น ๆ ที่วางตรงยอดพีคพอดี สเปกตรัมของมันวางความเพี้ยนไว้ที่ย่านสูง ซึ่งไฮแฮตและอาตั๊กบดบังได้ ความลึกเพิ่มตาม AMOUNT: 0.5 dB ตอนเริ่ม สูงสุด 2 dB เมื่อดันสุด

T8 — ลิมิตเตอร์ครึ่งคลื่น

T8 เปลี่ยนเกนเฉพาะตรงที่คลื่นตัดศูนย์ แต่ละครึ่งคลื่นของคิกและเบสถูกลดลงทั้งชิ้น รูปทรงจึงคงเดิมทุกประการ เปลี่ยนแค่ความสูง

หกย่านความถี่แบบเฟสเชิงเส้น: พีคเบสไม่เคยกดย่านสูง แต่ละย่านถูกลิมิตแยกกัน

T9 — ลิมิตเตอร์แบบเอนเวโลปสำหรับย่านต่ำ

T9 อ่านเอนเวโลปของเบสแทนที่จะอ่านทีละคลื่น: เกนจะรั้งยอดทั้งโน้ตไว้แล้วปล่อยอย่างนุ่มนวล ไม่สั่นในโน้ตซับที่ยาว

T8 | T9 คือสวิตช์เดียว การเปลี่ยนจะครอสเฟดใน 10 ms ไม่มีช่วงขาด ค่าเริ่มต้นคือ T9

ทุกอย่างที่ลิมิตเตอร์มาสเตอริงต้องมี

  • TRUE PEAK — เปิดเป็นค่าเริ่มต้น สำหรับสตรีมมิงและการส่งออก MP3
  • CEILING — −12…0 dB
  • CHARACTER — แซเชอเรชันเบา ๆ ก่อนลิมิตเตอร์
  • OUTPUT — ระดับหลังลิมิตเตอร์
  • LINEAR | NATURAL | CLEAN L — เฟสของแต่ละย่าน
  • OVERSAMPLE — 4x ถึง 64x ค่าเริ่มต้น 8x
  • MIX & MASTER — แค็ตตาล็อกวิศวกรมิกซ์และมาสเตอริงภายในปลั๊กอิน

ย่านต่ำสะอาด

เบสและคิกถูกลดลงทีละครึ่งคลื่นเต็ม ๆ รูปคลื่นจึงคงเดิม: ไม่หยาบ ไม่แตกพร่า

ย่านสูงสว่าง

ACR ย้ายความคลาดเคลื่อนจากการคลิปไปอยู่ตรงที่ไฮแฮตบดบังได้ ย่านสูงจึงยังโปร่งแม้ดันแรง

ไม่ปั๊ม

แต่ละย่านถูกลิมิตแยกกัน: พีคของคิกไม่เคยดึงเสียงร้องและย่านสูงลงไป

พร้อมสำหรับสตรีมมิง

TRUE PEAK เปิดเป็นค่าเริ่มต้น: ไม่มีโอเวอร์ระหว่างแซมเปิลหลังเข้ารหัส MP3, AAC หรือสตรีมมิง

T8 กับ T9 ต่างกันอย่างไร

ทั้งสองคุมเบสและตัวคิก T8 เปลี่ยนเกนเฉพาะจุดที่คลื่นตัดผ่านศูนย์ ทุกครึ่งคลื่นจึงคงรูปร่างเดิม T9 ตามเอนเวโลปของเบสและปล่อยโน้ตซับยาว ๆ อย่างนุ่มนวล ค่าเริ่มต้นคือ T9 สลับแล้วเลือกด้วยหูของคุณ

ใช้ร่วมกับ HOUZY ได้ไหม

ได้ วาง ACR LIMITER ไว้หลัง HOUZY บนมาสเตอร์: HOUZY ปรับการคอมเพรสให้สม่ำเสมอ ส่วน ACR LIMITER กำหนดความดังสุดท้ายและเพดาน เป็นปลั๊กอินแยกกัน มีไลเซนส์แยกกัน

เสียงของฉันออกจากคอมพิวเตอร์ไหม?

ไม่เลย การประมวลผลทั้งหมดเกิดขึ้นบนเครื่องของคุณ ปลั๊กอินออนไลน์เฉพาะตอนตรวจสอบอัปเดตและเปิดใช้งานไลเซนส์ รายละเอียดอยู่ในนโยบายความเป็นส่วนตัว (EN)

รองรับระบบและ DAW อะไรบ้าง

VST3 บน Windows 10/11 แบบ 64 บิต: Ableton Live, FL Studio, Cubase, Reaper, Bitwig และโฮสต์ VST3 อื่น ๆ บน macOS 10.15+ (Apple Silicon และ Intel): VST3 และ AU รวมถึง Logic Pro

เพิ่มเลเทนซีเท่าไร

ประมาณ 0.1 วินาที (การมองล่วงหน้าของลิมิตเตอร์และย่านความถี่เฟสเชิงเส้น) ปลั๊กอินรายงานค่านี้ให้ DAW ซึ่งชดเชยให้ ทุกแทร็กจึงยังตรงจังหวะ

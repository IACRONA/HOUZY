HOUZY

วิธีมาสเตอร์เพลงอิเล็กทรอนิกส์ด้วย HOUZY

คู่มือ HOUZY: เริ่มจากตรงไหน (AMOUNT ที่ 15–30) แต่ละปุ่มทำอะไรกับเสียง และจะปรับละเอียดเพลงอิเล็กทรอนิกส์และแดนซ์อย่างไร

AMOUNT · INPUT · CYCLES · RELEASE

สองนาทีจากการเปิด HOUZY สู่เพลงที่แน่นและสม่ำเสมอ คู่มือเดียวกันนี้มีอยู่ใน HOUZY ในการ์ด ACRONA

โหมด

เลือก HOUZY — ให้คุณภาพเสียงดีที่สุด

1. AMOUNT

เริ่มที่ปุ่ม AMOUNT สำหรับเพลงที่มิกซ์มาดี 15 ถึง 30 มักให้การบีบอัดที่นุ่มและพอดี กรณีอื่นให้ตั้งด้วยหู

2. INPUT

เมื่อการบีบอัดฟังเข้าที่แล้ว ค่อย ๆ เพิ่ม INPUT พร้อมดูมิเตอร์ LUFS สำหรับเสียงที่นุ่ม −10 ถึง −9 LUFS ก็พอ

3. CYCLES

สำหรับคิกที่นุ่ม ตั้งไว้ระหว่าง 3 ถึง 4

4. RELEASE

เปิด AUTO ไว้: ปลั๊กอินจะวัดว่าเสียงในเพลงจางหายเร็วแค่ไหน แล้วตั้งรีลีสให้คุณ

5. BEAT หรือ SMART

เลือกด้วยหู

  • BEAT คงรีลีสไว้ตรงตามที่ตั้ง: เสียงนิ่งกว่า เต้นไปกับจังหวะ
  • SMART ถือรีลีสเป็นค่าสูงสุด: เสียงที่จางเร็วกว่าจะถูกปล่อยเร็วกว่า โปร่งและเป็นธรรมชาติกว่า

ปรับละเอียด

  • DASH — ถ้าการบีบอัดฟังดีแล้ว แต่เพลงยังไม่สม่ำเสมอพอ เพิ่ม DASH เล็กน้อย
  • UPWARD — ยกส่วนที่เบา: หางรีเวิร์บ ความโปร่ง ย่านสูง
  • CLIP SHAPE — แซทูเรชันเบา ๆ ทั้งเพลง ความดังถูกปรับให้เท่ากันอัตโนมัติ คุณจึงได้ยินสีสันของเสียง ไม่ใช่เสียงที่ดังขึ้น
  • ALL MIX — ถ้าเพลงโดยรวมฟังแน่นแล้ว แต่ เช่น ย่านสูงหรือย่านกลางโดดออกมา ให้เปิด ALL MIX แล้วลดย่านนั้นด้วยปุ่มของมัน หากอยากรู้ว่าย่านหนึ่งครอบคลุมความถี่ใด ให้วางเคอร์เซอร์บนปุ่มของมันสักสองสามวินาที — ทิปจะแสดงช่วงความถี่

คลิปเปอร์: HI-Q หรือ ACR

เราแนะนำ ACR คลิปเปอร์ที่เราพัฒนาเอง มันย้ายความเพี้ยนไปไว้ตรงที่จังหวะกระแทกกลบได้ แอทแทคจึงยังสะอาด อย่างไรก็ตามเป็นเรื่องของรสนิยม — ลองทั้งสองแบบ

OVERSAMPLE

16x ก็เพียงพอระหว่างทำงาน ใช้ 32x สำหรับการเรนเดอร์ขั้นสุดท้าย

TRUE PEAK

ปุ่ม TP อยู่บนปุ่ม OUTPUT เปิดไว้เมื่อส่งออกสำหรับสตรีมมิง: มันกำจัดพีคระหว่างแซมเปิลที่จะแตกหลังแปลงเป็น MP3/AAC

สรุปสั้น ๆ

  1. AMOUNT 15 ถึง 30, CYCLES 3 ถึง 4
  2. เพิ่ม INPUT หากจำเป็น
  3. DASH และ UPWARD นิดหน่อยตามชอบ
  4. ใน ALL MIX ลดส่วนที่โดดออกมา
  5. เสร็จแล้ว

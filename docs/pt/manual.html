Como masterizar música eletrônica com o HOUZY

O manual do HOUZY: por onde começar (AMOUNT entre 15 e 30), o que cada controle faz com o som e como ajustar uma faixa de música eletrônica e dance.

AMOUNT · INPUT · CYCLES · RELEASE

Dois minutos entre abrir o HOUZY e ter uma faixa densa e uniforme. O mesmo guia está dentro do HOUZY, no cartão ACRONA.

Modo

Escolha o HOUZY: é o modo com a melhor qualidade de som.

1. AMOUNT

Comece pelo knob AMOUNT. Para uma compressão suave e moderada numa faixa bem mixada, valores entre 15 e 30 costumam bastar. Nos outros casos, ajuste de ouvido.

2. INPUT

Quando a compressão estiver boa, suba o INPUT de olho no medidor LUFS. Para um som suave, −10 a −9 LUFS é o suficiente.

3. CYCLES

Para um kick suave, coloque entre 3 e 4.

4. RELEASE

Deixe o AUTO ligado: o plugin mede o quão rápido os sons da sua faixa somem e ajusta o release sozinho.

5. BEAT ou SMART

: escolha de ouvido.

  • BEAT mantém o release exatamente como você definiu: um som mais uniforme, pulsando no ritmo.
  • SMART usa o release como máximo: se um som some antes, ele é solto antes. Soa mais arejado e natural.

Ajuste fino

  • DASH: se a compressão está boa mas falta uniformidade na faixa, adicione DASH.
  • UPWARD: levanta as partes baixas: caudas de reverb, ar, os agudos.
  • CLIP SHAPE: saturação leve na faixa inteira. O volume é compensado automaticamente, então você ouve a cor, não um aumento de volume.
  • ALL MIX: se a faixa soa densa no geral mas, por exemplo, os agudos ou os médios estão sobrando, ligue o ALL MIX e abaixe essa banda no knob dela. Para ver quais frequências uma banda cobre, deixe o cursor sobre o knob por alguns segundos: aparece uma dica com o intervalo.

Clipper: HI-Q ou ACR

Recomendamos o ACR, nosso próprio clipper. Ele leva a distorção para onde a batida a esconde, então os ataques ficam limpos. Mas é questão de gosto: teste os dois.

OVERSAMPLE

Para trabalhar, 16x é suficiente; para o render final, use 32x.

TRUE PEAK

O botão TP fica no knob OUTPUT. Ligue ao exportar para streaming: ele remove os picos entre amostras que estalam depois da conversão para MP3/AAC.

Resumindo

  1. AMOUNT entre 15 e 30, CYCLES entre 3 e 4.
  2. Suba o INPUT se precisar.
  3. Um pouco de DASH e UPWARD, a gosto.
  4. No ALL MIX, abaixe o que estiver sobrando.
  5. Pronto.
